# АЯ-Детектор — компоновка интерфейса (планшет, портретная ориентация)

Целевое устройство: планшет ~768×1024 px, портрет.

---

## Описание зон

### A — Панель режима (верх экрана, ~60px)
- Переключатель **ACTIVE / PASSIVE** — toggle с подсвеченной активной стороной
- Цветной LED-индикатор: 🔴 красный в активном режиме, 🟢 зелёный в пассивном
- Текстовая метка текущего режима

### B — Радарный модуль (~300px, квадрат по ширине экрана)
- Круговой PPI-дисплей с концентрическими кольцами дальности
- Вращающийся луч развёртки (зелёный, с затуханием шлейфа)
- Типы отметок целей:
  - `●` — источник ионизации
  - `Δ` — радиационная точка
  - `○` — ЭМ-аномалия
- Легенда типов — под кругом радара
- Масштаб (радиус охвата) меняется через щипок или кнопки `+` / `−`

### C — Датчики уровня (~130px, два столбца)
| Левый столбец | Правый столбец |
|---|---|
| Нейтронное излучение | Ионизация воздуха |
| Вертикальная шкала + число | Вертикальная шкала + число |
| Единица: мЗв/ч | Единица: % |
| Градация: зелёный / жёлтый / красный | Градация: зелёный / жёлтый / красный |

### D — Хроноаномальный индикатор (~50px)
- Одна строка: текущее отклонение внутренних часов от GPS-времени в миллисекундах
- Горизонтальный бар насыщенности отклонения
- Статус: **НОРМА** / **СЛАБОЕ** / **СИЛЬНОЕ** / **КРИТИЧЕСКОЕ**

### E — Инфразвуковой график (~160px)
- XY-график: X = частота (0–20 Гц), Y = амплитуда (дБ)
- Прокручивающаяся в реальном времени осциллограмма спектра
- Горизонтальная пунктирная линия — порог тревоги
- При превышении порога — зона под кривой подсвечивается красным

### F — Регуляторы (~80px, низ экрана)
- **Чувствительность** — влияет на минимальный порог регистрации всех модулей
- **Подавление помех** — фильтрует фоновый шум; при высоком значении возможны пропуски слабых сигналов
- Оба слайдера горизонтальные, с числовым значением справа

## Цветовая схема

| Элемент | Цвет |
|---|---|
| Фон приложения | `#0a0f1a` (глубокий тёмно-синий) |
| Радар / акценты | `#00ff88` (зелёный, «фосфор») |
| Предупреждение | `#ffaa00` (янтарный) |
| Тревога | `#ff2244` (красный) |
| Текст основной | `#c8e0f0` (холодный белый) |
| Панели / границы | `#1a2a3a` |

---

## Поведение в активном vs пассивном режиме

| Параметр | PASSIVE | ACTIVE |
|---|---|---|
| Радар | Только приём отражений | Отправляет зондирующий импульс |
| Луч развёртки | Медленный, тусклый | Быстрый, яркий |
| Цвет индикатора режима | Зелёный | Красный |
| Точность позиционирования | Низкая | Высокая |
| «Заметность» для объекта | Нет | Да (игровая механика) |
