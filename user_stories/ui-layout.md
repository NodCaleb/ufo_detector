## Описание зон

### A — Строка заголовка (верх экрана, ~36px)
- Слева: название устройства **АЯ-ДЕТЕКТОР** (зелёный фосфорный текст с свечением)
- Справа: текущее время `ЧЧ:ММ:СС` (приглушённый зелёный)
- Нет переключателя режимов — управление режимом поиска вынесено в правую колонку

### B — Радарный модуль (левая колонка, ~350px)
- Панель с заголовком **РАДИОЛОКАЦИОННЫЙ МОДУЛЬ**
- Внутри панели — горизонтальное расположение:
  - Левее: круговой PPI-дисплей 320×320 px с концентрическими кольцами дальности
  - Правее: вертикальная легенда типов отметок (6 типов, цветные точки)
- Вращающийся луч развёртки (зелёный, с затуханием шлейфа)
- Типы отметок целей (цветная точка + подпись):
  - Зелёный — ЭМ-аномалия
  - Янтарный — Излучение
  - Голубой — Ионизация
  - Оранжевый — Тепл. источник
  - Бирюзовый — Геомагн. возм.
  - Фиолетовый — Хронопертурб.

### C — Датчики уровня (левая колонка, ~150px, четыре столбца)
| Датчик 1 | Датчик 2 | Датчик 3 | Датчик 4 |
|---|---|---|---|
| Нейтрон. излуч. | Ионизация воздуха | Геомагн. поле | Тепловая аном. |
| Вертикальная шкала + число | Вертикальная шкала + число | Вертикальная шкала + число | Вертикальная шкала + число |
| Единица: мЗв/ч | Единица: % | Единица: нТл | Единица: °C |
| Градация: зелёный / жёлтый / красный | Градация: зелёный / жёлтый / красный | Градация: зелёный / жёлтый / красный | Градация: зелёный / жёлтый / красный |

### D — Хроноаномалия (левая колонка, ~40px, одна строка)
- Подпись **ХРОНОАНОМАЛИЯ** слева
- Текущее отклонение в секундах: `Δt +0.003с`
- Горизонтальный бар насыщенности отклонения
- Статус: **НОРМА** / **СЛАБОЕ** / **СИЛЬНОЕ** / **КРИТИЧЕСКОЕ**

### E — Инфразвуковой график (левая колонка, ~150px)
- Подпись **Инфразвук (0–20 Гц)**
- XY-столбчатый спектр: X = частота (0–20 Гц), Y = амплитуда (дБ)
- Обновляется в реальном времени
- Горизонтальная пунктирная линия — порог тревоги
- При превышении порога — столбцы окрашиваются красным

### F — Правая колонка (220px шириной, два блока по высоте)

#### F1 — Активный поиск (~верх колонки)
- Подпись **АКТИВНЫЙ ПОИСК**
- Кнопка `◉ АКТИВ` — переключает режим активного зондирования
- Строка статуса: LED-индикатор + текст **ВКЛ** / **ВЫКЛ**

#### F2 — Регуляторы (растягивается на оставшуюся высоту)
- Подпись **РЕГУЛЯТОРЫ**
- Два вертикальных слайдера рядом:
  - **ЧУВСТВ.** — чувствительность (85%)
  - **ПОМЕХИ** — подавление помех (42%)
- Каждый слайдер: числовое значение сверху, вертикальная шкала с подвижным ползунком, подпись снизу

## Поведение кнопки «Активный поиск»

| Параметр | ВЫКЛ (пассивный) | ВКЛ (активный) |
|---|---|---|
| Радар | Только приём отражений | Отправляет зондирующий импульс |
| Луч развёртки | Медленный, тусклый | Быстрый, яркий |
| LED-индикатор | Не светится | Красный, мигает |
| Кнопка | Без подсветки | Красная рамка + красное свечение |
| Точность позиционирования | Низкая | Высокая |
| «Заметность» для объекта | Нет | Да (игровая механика) |
